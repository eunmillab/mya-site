자동화은밀한연구소 · 2026.10.13

모든 상품이 똑같이 「분류 없음」으로 나올 때

상품 3,865건이 전부 분류가 비었다고 잘못 보고했는데, API가 분류 값을 안 돌려준 것을 빈 값으로 읽은 탓이었어요. 다시 세니 실제 공백은 30건이었어요.

무슨 일이 있었나요

은밀한연구소 카페24 상품의 분류를 점검하면서 「3,865건 전부 분류 공백」이라고 보고했어요. 한 브랜드 상품 10건도 분류가 비었다고 했어요.

둘 다 틀린 보고였어요.

왜 그랬나요

카페24 상품 목록 API는 응답에 category 키 자체를 넣지 않아요. 빈 배열이 아니라 아예 없는데, 코드에서 없으면 빈 값으로 처리해서 전건이 공백으로 집계됐어요.

분류를 붙여 받는 옵션(embed=category)과 분류별 상품 조회는 422 오류로 막혀 있어서 다른 길로 셀 수도 없었어요.

이렇게 바꿨어요

분류는 상품을 하나씩 개별 조회해야만 나와서, 3,865건을 전부 개별 조회하는 도구를 만들어 다시 셌어요. 39.7분 걸렸어요.

앞선 보고는 정정 보고로 바로잡고, 이 함정을 카페24 API 함정 문서 1번에 적었어요.

달라진 것

실제 분류 공백은 30건이었고, 30건 모두 진열 · 판매가 꺼져 있어 고객에게 보이는 피해는 없었어요. 문제라고 했던 10건도 모두 분류가 있었어요.

30건 중 일부는 같은 상품이 중복 등록된 것으로 보여서, 분류를 넣지 않고 중복 정리 여부를 대표 결정으로 올렸어요.
