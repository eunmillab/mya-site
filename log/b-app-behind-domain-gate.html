AI로 만든 앱을 내 도메인에 연결해야 할 때

챙겨 앱 본체는 Claude 아티팩트 주소에 있어 도메인으로 옮길 수 없었고, 소개 → 로그인 관문 → 앱 세 겹으로 사이트를 짰어요.

무슨 일이 있었나요

챙겨 도메인을 샀지만, 앱 본체는 Claude 아티팩트 주소로만 열렸어요. 자체 회원가입과 로그인은 아직 정하지 않은 상태였어요.

왜 그랬나요

앱이 아티팩트 안에서 돌아서 도메인 서버로 그대로 옮길 수 없었어요. 앱 주소를 소개 페이지 곳곳에 박아 두면, 나중에 호스팅을 옮길 때 그 링크를 다 찾아 바꿔야 해요.

이렇게 바꿨어요

사이트를 소개, 로그인 관문, 앱 세 겹으로 나눴어요. 소개 페이지의 시작 단추 3곳은 전부 /login 으로 보내고, 소개에는 앱 주소를 하나도 넣지 않았어요.

관문 페이지에는 「Claude 계정으로 로그인」, 「먼저 설명서 읽기」, 초대 받는 법 3단계만 두고 검색에서 빼게 했어요. /app · /guide 는 넘겨주기 규칙으로 처리했어요.

관문 아이콘이 흰 바탕으로 보이던 문제도 잡았어요. SVG 크기를 바꾸는 치환이 배경 사각형에도 걸려 배경 크기가 사라졌던 거라, 배경 사각형만 되돌렸어요.

달라진 것

사이트 폴더 하나가 원본이 되고, 아티팩트 미리보기판은 상대 주소만 바꿔 같이 돌아가요. 먀 사이트에도 챙겨 페이지를 올려 정상으로 열리는 걸 확인했어요.

앱 주소가 바뀌어도 관문 한 곳만 고치면 되게 됐어요. 도메인 연결은 대표 계정 작업으로 남아 있어요.

다음에도 쓰는 기준

앱 주소가 바뀔 수 있으면 손님에게는 관문 주소 하나만 알려 주고, 실제 앱 주소는 관문 뒤에서 바꾼다.
