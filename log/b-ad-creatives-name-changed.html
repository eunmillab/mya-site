AD광고 소재챙겨 · 2026.10.15

광고 소재를 다 만든 날 서비스 이름이 바뀔 때

챙겨 광고 소재 10개를 만든 날 문구와 이름이 두 번 바뀌었고, 글자를 생성 모델에 맡기지 않은 덕에 같은 날 전부 다시 냈어요.

무슨 일이 있었나요

노션과 슬랙 값을 한 화면으로 줄인다는 광고 소재를 사진 7개, 영상 3개로 만들었어요.

그날 「오픈 전 초대 무료」 문구가 추가됐고, 저녁에는 대표가 「챙겨도 AI는 안 붙일 거야」로 이름을 바꿨어요. 소재 10개 전부에 이름이 들어가 있었어요.

왜 그랬나요

요금과 이름이 정해지기 전에 소재를 만들었어요.

AI 영상 모델은 화면 속 글자와 숫자를 뭉개기 쉬워서, 영상을 매번 새로 뽑으면 글자가 바뀔 위험도 같이 커져요.

이렇게 바꿨어요

사진 소재는 HTML 본문과 실제 앱 캡처로 만들었어요. 문구만 바꾸고 다시 렌더하면 끝나요.

영상은 글자와 숫자가 다 들어간 세로 스틸을 우리가 먼저 만들고, 모델에는 카메라와 빛의 움직임만 맡겼어요. 뽑은 뒤에는 프레임을 한 시트에 나란히 놓고 글자가 그대로인지 확인해요.

처음 고른 영상 모델은 요금제 문제로 막혀서, 다른 모델로 바꿔 768 해상도로 만들었어요.

달라진 것

3차까지 같은 날 사진 7장을 다시 렌더하고 영상 3개를 다시 뽑아, 10개 전부 새 이름과 문구로 바꿨어요. 프레임 확인에서 글자 · 숫자 · 캡처는 그대로였어요.

영상 하나는 배경이 살짝 초록빛으로 틀어졌고, 영상 비율 때문에 위아래가 조금 잘려서 집행 전에 고칠 것으로 남겼어요.

다음에도 쓰는 기준

광고 소재의 글자는 생성 모델에 맡기지 않고 우리가 만든 스틸과 HTML 에 둔다. 모델에는 움직임만 맡겨야 문구가 바뀌어도 바로 다시 낼 수 있다.
