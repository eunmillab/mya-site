문법 검사는 통과했는데 브라우저에서만 스크립트가 죽을 때

챙겨 붙여넣기 기능을 만들다 두 번 막혔는데, 로컬 서버의 문자 인코딩과 구형 사파리가 모르는 정규식 문법이 원인이었어요.

무슨 일이 있었나요

node --check 문법 검사를 통과한 파일이 브라우저에서 띄우자 SyntaxError를 내며 죽었어요. 원인을 찾느라 한 번 헤맸어요.

할 일을 쪼개는 정규식 때문에 구형 사파리에서는 스크립트가 통째로 죽는 문제도 있었어요.

왜 그랬나요

로컬 확인용으로 띄운 python3 -m http.server 가 charset=utf-8 을 붙이지 않았어요. 브라우저가 파일을 latin-1로 읽어서 한글 식별자(그리기, 묶음)가 깨졌어요.

룩비하인드 (?<=...) 정규식은 구형 사파리가 지원하지 않아요. 스크립트가 파싱에서 실패하면 전체가 멈춰요.

이렇게 바꿨어요

한글 식별자를 쓰는 파일은 charset을 붙여 주는 서버로 띄워 확인하기로 했어요.

룩비하인드를 빼고 마커로 치환한 뒤 split 하는 방식으로 바꿨어요.

달라진 것

브라우저 실행에서 붙여넣기 · 쪼개기 · 추가 · 지우기가 모두 정상 동작했어요. 묶음 수도 9개에서 10개로 늘어나는 것까지 확인했어요.

다음에도 쓰는 기준

문법 검사 통과와 브라우저 실행은 다르다. 한글이 든 파일은 charset을 확인하고, 구형 브라우저가 모르는 문법은 피한다.
