상품 크기 데이터에 무게가 섞여 있을 때

치수 파서가 「450g」을 높이 450mm로 읽고 있었고, 규칙 네 가지로 다시 짜서 1,261건에 사이즈 안내를 넣었어요.

무슨 일이 있었나요

상세페이지에 사이즈 안내를 넣으려고 치수 데이터를 보니, 원문 「160 x 70 x 70mm (450g)」의 높이가 450mm로 잡혀 있었어요.

무게 표기가 든 행 267건 중 233건(전체 1,285건의 18%)이 무게를 치수로 읽었고, 높이가 실제로 틀어진 것은 158건이었어요.

왜 그랬나요

기존 파서는 5~600 사이 숫자를 단위와 상관없이 전부 치수로 봤어요.

한 줄에 「길이 15cm 폭 6.5cm」처럼 단위가 섞이거나, 단위 없이 「16.5 x 7.5 x 7.5」로 적힌 것도 있었어요. 내부 길이나 케이블 길이 같은 보조 치수도 섞여 있었어요.

이렇게 바꿨어요

규칙을 네 가지로 다시 짰어요. 무게를 먼저 지우고, 보조 치수를 지우고, 숫자마다 뒤의 단위를 보고, 단위가 없고 숫자가 모두 작으면 cm로 읽어요.

허용 범위는 10~1500mm로 넓혔어요. 실제로 70~120cm인 상품이 있어 상한 600으로는 담을 수 없었어요.

기계로 가를 수 없는 경고 21건은 자동 삽입에서 빼고 대표 확인으로 넘겼어요.

상세설명 맨 아래에 치수 원문 한 줄과 도식을 붙이고, 표식 주석으로 중복 삽입을 막아 다시 돌려도 안전하게 했어요. 기존 설명은 건드리지 않았어요.

달라진 것

정상으로 읽힌 1,262건 중 1,261건에 넣었고 실패는 0이었어요. 남은 1건은 미리 시험으로 넣어 둔 상품이에요.

정상 높이 분포가 최소 35mm, 중앙 153mm, 최대 550mm가 되면서 전에 있던 1,900mm 같은 값이 사라졌어요.

다음에도 쓰는 기준

숫자를 읽을 때는 단위를 같이 읽는다. 무게처럼 다른 단위의 숫자는 먼저 걷어낸다.
