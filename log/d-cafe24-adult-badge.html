성인 상품 사진이 마우스만 올려도 보일 때

카페24가 걸러 내는 스타일 대신 스크립트로 19 표시를 바꾸고, 마우스를 올리면 실제 사진이 드러나던 구멍까지 막았어요.

무슨 일이 있었나요

한 분류 페이지 1쪽 상품 20개 중 16개가 성인인증 없이 실제 상품 사진 그대로 보였어요. 상품마다 성인인증 설정이 달랐어요.

가려진 상품도 마우스를 올리면 미리보기 사진이 드러났어요. 19 표시는 카페24 기본 빨간색이었는데 관리자에 바꾸는 메뉴가 없었어요.

왜 그랬나요

스킨 파일에 넣은 `<style>`은 저장 요청이 성공했는데도 실제 페이지에 나오지 않았어요. 카페24가 모듈 파일 안의 스타일을 걸러 내는 것으로 보였어요.

footer 파일에만 넣었을 땐 상품 목록에서 먹지 않았어요. 메인과 하위 페이지가 서로 다른 레이아웃 파일을 썼기 때문이에요.

이렇게 바꿨어요

`<style>` 대신 `<script>`를 넣었어요. 19 이미지 주소를 브랜드 실버 뱃지로 바꾸고, 늦게 불러오는 이미지까지 잡도록 화면 변화를 감시해요. 마우스 오버 미리보기 요소는 숨겨요.

메인용 footer, 상품 분류 화면, 상품 상세 화면 세 곳에 넣었어요. 상품별 성인인증 설정은 팝업 창이라 자동화가 안 돼서, 엑셀 일괄 수정을 대안으로 적었어요.

달라진 것

같은 분류 페이지에서 20개 전부 실버 뱃지, 빨간 표시 0, 사진 노출 0, 마우스 오버 미리보기 20개 전부 숨김을 확인했어요.

다음 날 카페24 운영을 접기로 해서 이 작업은 거기서 멈췄지만, 원본 파일을 바꿀 수 없는 화면을 스크립트로 덮는 방법과 확인 절차는 기록으로 남겼어요.
