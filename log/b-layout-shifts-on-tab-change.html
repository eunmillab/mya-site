목록을 거를 때마다 화면이 옆으로 밀릴 때

챙겨 앱에서 목록 길이에 따라 화면이 흔들리고 카드가 밖으로 나가던 문제를 CSS 몇 줄로 잡았어요.

무슨 일이 있었나요

거르개를 바꿔 목록이 짧아지면 가운데 칸이 옆으로 밀렸어요. 대표는 「옆으로 밀리는 느낌나」라고 했어요.

채팅 방 목록을 2열로 보면 966px 폭에서 카드가 화면 밖으로 나갔어요. 설명서의 순서 번호는 카드보다 40px 밀려 있었어요.

왜 그랬나요

목록이 짧아져 세로 스크롤바가 사라지면, 그 폭만큼 가운데 칸이 옆으로 움직여요.

2열 격자를 1fr 로 잡으면, 한 줄로 고정된 멤버 이름처럼 줄어들지 않는 내용이 있을 때 칸이 커져요.

번호 목록(ol)에는 브라우저 기본 들여쓰기 40px 이 붙어 있었어요.

이렇게 바꿨어요

html 에 scrollbar-gutter: stable both-edges 를 줘서 스크롤바 자리를 늘 비워 두게 했어요.

2열 격자는 minmax(0, 1fr) 로 바꾸고, 번호 목록의 기본 들여쓰기를 없앴어요.

다섯 탭의 머리 구조를 같게 맞추고, 탭마다 스크롤 자리를 기억해서 바꿀 때 튀지 않게 했어요.

달라진 것

320 · 390 · 966 · 1200 네 폭에서 다섯 탭을 다시 훑어 넘침 · 잘림 · 겹침이 0 인 걸 확인했어요.

다만 미리보기 브라우저는 스크롤바가 화면 위에 겹쳐 뜨는 방식이라 밀림 자체는 재현하지 못했어요. 그래서 대표 화면에서 한 번 더 보도록 남겨 뒀어요.

다음에도 쓰는 기준

화면 점검은 320 · 390 · 966 · 1200 네 폭으로 하고, 2열 격자는 처음부터 minmax(0, 1fr) 로 쓴다.
