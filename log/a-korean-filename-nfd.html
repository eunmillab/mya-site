한글 파일 이름이 검색에 안 잡힐 때

바탕화면의 「스크린샷」 파일을 찾는 코드가 0개를 돌려줬는데, 맥이 한글을 자모로 나눠 저장한 탓이었어요.

무슨 일이 있었나요

바탕화면과 다운로드 폴더를 정리하는 도구에서 「스크린샷*.png」로 파일을 찾았더니 0개가 나왔어요. 바탕화면에는 스크린샷 파일이 분명히 있었어요.

왜 그랬나요

맥은 파일 이름의 한글을 자모가 나뉜 형태(NFD)로 저장하는 경우가 있어요. 코드에 적은 「스크린샷」은 합쳐진 형태(NFC)라서, 눈으로는 같은 글자인데 일치하지 않았어요.

이렇게 바꿨어요

폴더 목록을 직접 읽고 이름을 NFC로 맞춘 뒤 비교하도록 바꿨어요.

파일은 날짜 묶음만 보고 넘기지 않고 내용을 하나씩 확인해서 작업 건 폴더 · 참고 폴더 · 받은자료로 나눴어요. 견적 금액이 찍힌 캡처는 외부 공유 금지라 건별 폴더 안에만 두었어요.

지울 후보는 지우지 않고 따로 모아 대표가 보고 비우게 했어요.

달라진 것

스크린샷 4개를 다 잡았어요. 36개를 옮기고 실패 0, 삭제 0이었어요.

바탕화면은 8개에서 4개, 다운로드 폴더는 32개 308MB에서 0개가 됐어요.

다음에도 쓰는 기준

한글 파일 이름을 비교할 땐 양쪽을 NFC로 맞춘다. 파일 정리 도구는 옮기기만 하고 지우는 건 사람이 한다.
