AUTO자동화먀 자체 · 2026.10.20

AI에게 바탕화면 정리를 맡길 때 아무것도 지우지 않게 한 방법

없는 기능으로 정리하라는 지시를 먼저 바로잡고, 파일을 옮기기만 해서 낱개 23개를 0개로 만들고 되돌리기 스크립트를 남겼어요.

무슨 일이 있었나요

대표가 「챙겨 통해서 바탕화면이랑 다운로드 파일 좀 정리해주고 영상으로 찍어줘」라고 했어요. 바탕화면에는 낱개 파일 21개, 다운로드에는 2개가 흩어져 있었어요.

왜 그랬나요

챙겨는 할 일 · 일정 · 비용을 챙기는 작업실이라 파일 정리 기능이 없었어요. 소스 363KB를 검색해 파일 접근 관련 코드가 0건인 걸 확인했어요. 없는 기능으로 했다고 하면 거짓 보고가 돼요.

파일 정리는 잘못 지우면 되돌릴 수 없어서, 정리 방식 자체가 안전해야 했어요.

이렇게 바꿨어요

챙겨에 기능이 없다는 걸 먼저 알리고, 정리는 셸로 직접 했어요. 지우지 않고 종류별 폴더로 옮기기만 했고, 폴더 이름은 다운로드에 이미 있던 방식을 따랐어요.

내용이 같은 파일은 sha256으로 대조해 1건을 찾았지만 지우지 않고 「중복_확인후삭제」 폴더에 넣었어요. 이름만 비슷하고 크기가 다른 파일은 중복으로 보지 않았어요. 옮긴 기록을 남기고, 23개를 원래 자리로 돌리는 스크립트를 만들어 문법 검사까지 했어요.

달라진 것

바탕화면과 다운로드의 낱개 파일이 0개가 됐고, 지운 파일은 0개예요. 옮긴 자리에 23개가 모두 있는 것도 확인했어요.

시연 영상은 실제 파일 이름과 실제 분류 결과로 그렸어요.
