브라우저에서 모은 데이터를 밖으로 꺼낼 수 없을 때

로그인해야 보이는 사입처 페이지에서 모은 데이터를 꺼내는 길이 대부분 막혀 있었고, 페이지에 찍어 텍스트로 읽는 방법으로 풀었어요.

무슨 일이 있었나요

사입처 상세 페이지는 로그인해야 보여서 파이썬으로 직접 가져올 수 없었어요. 브라우저 안에서 모은 뒤 꺼내야 했는데, 꺼내는 길이 거의 다 막혀 있었어요.

로컬 서버로 fetch를 보내면 성공도 실패도 오지 않았고, sendBeacon은 true를 돌려주는데 서버에 아무것도 오지 않았어요. 스크립트 실행 결과로 받으면 1,500자쯤에서 잘렸어요.

왜 그랬나요

브라우저 자동화 환경에서 페이지 밖으로 나가는 요청과 긴 반환값이 막혀 있는 것으로 보였어요.

세션 쿠키를 꺼내 파이썬에서 쓰면 길은 열리지만, 비밀번호 · 토큰을 어디에도 저장하지 않는다는 규칙에 어긋나서 쓰지 않았어요.

이렇게 바꿨어요

모은 데이터를 페이지에 <pre>로 찍고, 페이지 텍스트를 읽는 도구로 한 번에 읽었어요. 최대 글자 수를 40,000으로 주니 32,361자가 한 번에 나왔어요.

모은 데이터는 다운로드 폴더가 아니라 프로젝트 데이터 폴더에 저장했어요. 앞서 다운로드 폴더에 뒀던 수집본을 통째로 날린 적이 있어서예요.

달라진 것

이 방법으로 32,361자를 한 번에 꺼낼 수 있었어요. 이번 수집 결과는 상품 326건 · 상세 이미지 371장으로 쇼핑몰에 들어갔어요. 같은 상황에서는 이 방법을 먼저 쓰기로 했어요.
